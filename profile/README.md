## Что можно ввести в поиск

Проще всего начать с точного параметра. Телефон вводят полностью, с кодом страны. Для Telegram подходят @username и числовой ID. Страницу ВКонтакте можно проверить по ссылке или ID; для Instagram и TikTok используйте ссылку либо имя пользователя в поддерживаемом формате. Если у вас только имя и фамилия, добавьте город или дату рождения, когда они известны. Так список однофамильцев будет короче.

Почту тоже можно отправить боту. Иногда полезен даже её фрагмент, но полный адрес обычно понятнее как стартовый запрос. По фотографии есть отдельный поиск похожих профилей, если он доступен в вашем режиме работы. Сама найденная страница затем становится новой зацепкой: её можно проверить по ссылке, ID или нику.

Запросы «глаз пробив», «пробив глаз бога» и glaz boga часто появляются у тех, кто ещё не знает, с какого поля начать. Не нужен длинный список данных о человеке. Одного номера, ника или профиля достаточно, чтобы отправить первый запрос и посмотреть, есть ли у него продолжение в доступных записях.

## Как один запрос приводит к следующему

Допустим, вы знаете Telegram-ник. По нему может найтись телефон, с которым аккаунт связывали раньше. Проверяете номер отдельно и видите почтовый адрес или другую соцсеть. Почту отправляете третьим запросом. Так из одного ника получается маршрут: Telegram → телефон → почта и профили. У каждого шага есть конкретная причина, поэтому не приходится угадывать среди похожих имён.

Другой пример начинается с ВКонтакте. Ссылка или ID страницы могут привести к записи с номером либо почтой. По найденному контакту ищутся другие аккаунты, в том числе Telegram, если связь есть в источниках. Прямой ссылки на него в профиле может не быть. Бот помогает найти связь через данные, которые встречались рядом с аккаунтом в записях.

Если известны только ФИО и город, первый ответ может содержать несколько людей. Сравните дополнительные поля и перейдите к более точному параметру: телефону, почте или профилю. У распространённой фамилии такой второй шаг особенно полезен. Он помогает не смешать сведения разных однофамильцев.

## Когда нужен более подробный отчёт

В боте есть глубокий поиск по поддерживаемым параметрам: человеку, телефону, почте, ИНН и некоторым другим данным. Такой отчёт может собрать больше найденных полей, включая контакты, документы, адреса и связанные аккаунты. Глубокий поиск оплачивается отдельно от обычной подписки. Перед запуском посмотрите текущие условия в боте и выберите режим под свою задачу.

В результатах обычного и глубокого поиска могут встречаться исторические записи. Например, старый номер или прежний ник иногда помогает найти профиль того периода. Если рядом указана дата, учитывайте её при дальнейшем поиске. Запись из прошлого полезна как зацепка, но нынешние данные человека лучше сверять с более свежими источниками, которые у вас есть.

Для автомобиля предусмотрен поиск по госномеру или VIN, для организации по ИНН. Это отдельные сценарии с другими типами ответа. Их не стоит смешивать с поиском аккаунта: выбирайте параметр, который действительно относится к вашей задаче.

## Коротко о частых вопросах

### Можно ли пробить человека через Глаз Бога без телефона?

Да. Начните с ника или ID в Telegram, ссылки на соцсеть, имени с городом, почты либо другого поддерживаемого параметра. Телефон может появиться уже в ответе.

### Что даёт пробив бот Глаз Бога по номеру?

Если номер встречался в доступных записях, рядом могут быть имя, подписи контактов, почта или аккаунты. Найденное поле удобно проверить следующим запросом.

### Можно ли найти Telegram по странице ВКонтакте?

По ссылке или ID страницы иногда находится телефон либо почта. Проверка этого контакта может привести к Telegram-аккаунту, когда такая связь есть в записях.

### Как пользоваться результатом аккуратно?

Проверяйте свои данные, сведения с согласия человека или в другой правомерной ситуации. Не выкладывайте чужие контакты и целые отчёты в открытый доступ. Если запись старая, посмотрите её дату перед тем, как опираться на неё.
